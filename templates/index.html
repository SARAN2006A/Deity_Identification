Backend REST API Endpoint

The Flask backend exposes a POST endpoint at /api/predict. You can submit standard multipart form data containing an image file.

curl -X POST -F "file=@sculpture.jpg" http://127.0.0.1:5000/api/predict

Response Schema (JSON):

{ "success": true, "best_guess": "murugan", "best_confidence": 92.4, "predictions": [ { "class": "murugan", "confidence": 92.4 }, { "class": "shivan", "confidence": 4.1 }, ... ] }
